# העלאת "חדר הלבשה" לאוויר: צעד אחר צעד

בסוף התהליך יש קישור אחד שפותחים באייפון של איה ומתקינים למסך הבית.
הכול חינמי. יש חלק אחד אופציונלי בתשלום (חלק ג׳), והוא כבוי עד שמגדירים אותו.

## חלק א׳: פריסה ל-Vercel (חינם, כ־5 דקות)

1. נכנסים ל-https://vercel.com ונרשמים עם חשבון ה-GitHub שבו נמצא הריפו.
2. לוחצים **Add New → Project** ובוחרים את הריפו `John`.
3. במסך ההגדרות:
   - **Root Directory**: לוחצים Edit ובוחרים `dressing-room`. זה הצעד החשוב ביותר.
   - **Framework Preset**: Vite (מזוהה לבד).
   - את שאר השדות משאירים כמו שהם.
4. ב-**Git → Production Branch** (Settings של הפרויקט) בוחרים את הענף `claude/gallant-wright-bevvul`,
   או ממזגים אותו קודם ל-`main`.
5. לוחצים **Deploy**. אחרי כדקה מתקבל קישור בסגנון `https://john-xxxx.vercel.app`.

## חלק ב׳: התקנה באייפון של איה

1. פותחים את הקישור **בספארי** (לא בכרום ולא מתוך וואטסאפ).
2. לוחצים על כפתור השיתוף ← **הוסף למסך הבית**.
3. מעכשיו פותחים את האפליקציה רק מהאייקון שבמסך הבית.

חשוב: מתקינים **לפני** שמעלים תמונות. התוכן בספארי ובאפליקציה המותקנת נשמר בנפרד,
ומה שנשמר בספארי עלול להימחק אחרי שבוע בלי שימוש.

בפעם הראשונה שמסירים רקע, האפליקציה מבקשת אישור להוריד את כלי הסרת הרקע (כ־80MB, פעם אחת). עדיף על Wi-Fi.

## חלק ג׳: מדידה ריאליסטית אוטומטית (אופציונלי, בתשלום, כבוי כברירת מחדל)

האפליקציה עובדת במלואה בלי החלק הזה, ושום דבר לא מחויב. מי שרוצה תמונה שנראית כמו צילום אמיתי,
בלחיצה אחת, יכול להפעיל חיבור לשירות AI. זה עולה כ־4 סנט לתמונה.

1. נרשמים ב-https://fal.ai, מוסיפים אמצעי תשלום וטוענים יתרה קטנה.
2. ב-fal.ai: **Dashboard → API Keys → Create key**. מעתיקים את המפתח.
3. ב-Vercel: בפרויקט → **Settings → Environment Variables**, מוסיפים:

   | Name | Value |
   |---|---|
   | `FAL_KEY` | המפתח מ-fal.ai |
   | `APP_PIN` | סיסמה שתבחרו, **לפחות 12 תווים**. רק מי שיודע אותה יכול להפעיל את ה-AI על חשבונכם |

4. **Deployments → ⋯ → Redeploy**.
5. באפליקציה: הגדרות ← "הפעלת מדידה ריאליסטית אוטומטית", מאשרים ומקלידים את ה-`APP_PIN`.
   אחרי ההפעלה מופיע כפתור ✦ במסך המדידה.

המפתח נמצא רק בשרת של Vercel. אל תשלחו אותו בצ׳אט ואל תכניסו אותו לקובץ בריפו.
קרדיטים של מנוי Higgsfield אינם ניתנים לשימוש דרך API (הוא מחויב בנפרד), ולכן המסלול האוטומטי עובר דרך fal.ai.

## גיבוי

הגדרות (גלגל השיניים) ← **גיבוי הארון לקובץ** ← **שמירת קובץ הגיבוי**. שומרים את הקובץ ב"קבצים" או ב-iCloud.
**שחזור מקובץ** מחליף את כל התוכן באפליקציה בתוכן הקובץ, וכך גם מעבירים הכול לטלפון חדש.

## עדכונים

כל push לענף שנבחר ב-Vercel מעלה גרסה חדשה. האפליקציה המותקנת מתעדכנת בפתיחה הבאה שלה עם אינטרנט.
