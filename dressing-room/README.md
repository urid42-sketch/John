# חדר הלבשה

אפליקציית הלבשה פרטית: מעלים תמונת גוף מלא, מייבאים בגדים, מודדים אותם על הדמות,
מעצבים בגדים בסטודיו ושומרים לוקים. הכול נשמר מקומית בדפדפן (IndexedDB), בלי התחברות ובלי ענן.
היוצא מן הכלל היחיד הוא המדידה הריאליסטית (AI), שפועלת רק אחרי אישור מפורש.

**פריסה והתקנה בטלפון: ראו [DEPLOY.md](DEPLOY.md).**

## הרצה

```bash
cd dressing-room
npm install
npm run dev        # http://localhost:5173, וגם בכתובת הרשת המקומית
```

בדיקה בטלפון: המחשב והטלפון על אותו Wi-Fi, ופותחים בטלפון את כתובת ה-Network ש-Vite מדפיס
(למשל `http://192.168.1.20:5173`). הדבקה מהלוח וחלק מהיכולות דורשות HTTPS, ולכן הבדיקה המלאה
בטלפון נעשית על כתובת הפריסה ב-Vercel (Root Directory: `dressing-room`).

## פקודות

- `npm run build` – בדיקת טיפוסים ובנייה ל-`dist/`
- `npm run test` – בדיקות יחידה (Vitest)
- `npm run preview` – הרצת הגרסה הבנויה

## רישוי

הסרת הרקע משתמשת ב-`@imgly/background-removal` (AGPL-3.0). המודל (כ-80MB) יורד פעם אחת בשימוש הראשון.

## מבנה

- `src/` – האפליקציה (React + Vite + TypeScript + Tailwind, קנבס ב-Konva)
- `src/engine/` – מנוע הגזרות הפרמטרי (פונקציות טהורות, עם בדיקות)
- `api/ai.js` – פונקציית serverless ל-Vercel עבור ה-AI. מפתחות רק במשתני סביבה

תכנון מלא: `docs/ARCHITECTURE.md`.
